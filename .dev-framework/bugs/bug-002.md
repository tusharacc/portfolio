# Language chip backgrounds may look jarring in light mode

Chip backgrounds use dark hex values (e.g. `#0a1929`) designed for dark mode.
In light mode, cards are white but chips retain dark backgrounds — technically readable
but visually inconsistent. Consider lighter chip backgrounds for `html:not(.dark)` context.
