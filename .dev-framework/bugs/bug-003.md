# @sveltejs/adapter-auto unused in devDependencies

`package.json` lists `@sveltejs/adapter-auto` but `svelte.config.js` imports
`@sveltejs/adapter-static` only. The auto adapter is never used.

**Fix**: `npm uninstall @sveltejs/adapter-auto`
