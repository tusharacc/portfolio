# Tech timeline mobile layout: rows stay 3-wide, not single column

At ≤480px, `TechTimeline.svelte` changes `.trace-h` to a vertical line but the
parent flex container keeps `flex-direction: row/row-reverse`, so 3 year nodes
remain side by side (each ~160px wide) instead of stacking into a single column.

**File**: `src/lib/components/TechTimeline.svelte:162-173`

**Fix**: Inside `@media (max-width: 480px)`, add:
```css
.flex { flex-direction: column !important; }
```
Or wrap each row's container in a `.row` class and override it there. Also reset
`.trace-h` to a centred vertical connector rather than `margin-left: 18px`.
